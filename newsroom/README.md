# חדר החדשות — איך עובדים

זו התיקייה שחוזרים אליה בכל פעם. כל מה שהצוות צריך נמצא כאן, והמוד שמפעיל אותו קיים רק בפרויקט הזה.

## לפתוח יום עבודה
1. פותחים סשן חדש של Claude Code בתיקייה `C:\pysical ai magazine` (באפליקציה: בוחרים את התיקייה הזו).
2. כותבים `/newsroom` — נפתחת חלונית "חדר חדשות" ליד הצ'אט.
3. אם השרת כבוי, בחלונית כתוב "השרת כבוי": כותבים `/newsroom start`.

בפרויקט אחר אין `/newsroom` ואין חלונית. המוד יושב ב-`newsroom/mod/` ומותקן בהיקף פרויקט: ההתקנה רשומה רק ב-`.claude/settings.json` של התיקייה הזו (`enabledPlugins` ו-`extraKnownMarketplaces`). בפרויקט אחר הוא מופיע ב-`claude plugin list` כ-disabled.

בפעם הראשונה שפותחים סשן בתיקייה, ייתכן ש-Claude Code ישאל אם לסמוך על ה-marketplace המקומי `pam-newsroom`. מאשרים.

## מה רואים בחלונית
- **שרת:** Paperclip פעיל או כבוי (`http://localhost:3100` — אפשר לפתוח גם בדפדפן ללוח המלא).
- **גיליון היום:** באיזה שלב הוא — מחקר ← בדיקת עובדות ← עריכה ופרסום — וקישור כשהוא באוויר.
- **הצוות:** כל סוכן, מצבו, וכמה מהתקציב החודשי נוצל.
- **ממתין לך:** אישורים, עם כפתורי אישור ודחייה.
- **שמות:** הסבב האחרון מלוח השמות.

מעל תיבת הכתיבה מופיעה שורה קצרה עם אותו מצב, למשל "גיליון היום: בבדיקת עובדות · אישור אחד ממתין".

## פקודות
| פקודה | מה עושה |
|---|---|
| `/newsroom` | פותח את החלונית |
| `/newsroom start` · `/newsroom stop` | מפעיל או עוצר את שרת Paperclip של הפרויקט |
| `/newsroom issue` | מפעיל עכשיו את "גיליון היום" (בלי לחכות ל-07:00) |
| `/newsroom approve <id>` · `/newsroom reject <id>` | אישור או דחייה (אותו דבר כמו הכפתורים) |
| `/newsroom pause <סוכן>` · `/newsroom resume <סוכן>` | עצירה או חידוש של סוכן (`editor`, `reporter`, `checker`, `publisher`, `brand`, `developer`) |
| `/newsroom names` | מציג את בריף השמות ואת הסבב האחרון |
| `/newsroom setup` | מחיל שינויים מ-`company.json` על Paperclip |

## אם הריצה נתקעת
- **סימן:** כל הסוכנים במצב `idle` ומשימה פתוחה לא זזה כבר כמה דקות (`/newsroom` או `node scripts/newsroom.mjs status`).
- **טיפול:** `node scripts/newsroom.mjs wake editor` מעיר את העורך הראשי, והוא מקריא את המשימות והקבצים ומחליט על הצעד הבא. אפשר להעיר גם סוכן אחר: `wake reporter`, `wake checker`, `wake publisher`.
- **למה זה קורה:** סוכן שסיים לא תמיד מצליח להעביר את המשימה הלאה בעצמו (ל-Paperclip יש כלים שלא מתחברים בהרצה הזו). לכן הכתב סוגר את המשימה כ-`done`, והעורך קורא תגובות וקבצים ולא מסתמך על סטטוס בלבד (כתוב בהנחיות שלהם). נדרשה הערה ידנית אחת בריצה הראשונה.
- **שרת שלא עולה:** אחרי עצירה קשה, Postgres משחזר את עצמו כמה דקות. `start` ממתין עד 6 דקות.

**הפעלה ידנית בלבד** (מ-23.10.2026): הצוות לא רץ לבד. כל השגרות ב-`company.json` מושהות, וגם המשימה המתוזמנת הישנה `physical-ai-magazine-daily` ומשימת השמירה `newsroom-server-keepalive`.

- **לחזור ללוח זמנים אוטומטי:** ב-`company.json` משנים את `status` של השגרות ל-`active` ומריצים `/newsroom setup`. אחר כך מפעילים מחדש את `newsroom-server-keepalive` בתפריט Scheduled באפליקציה.
- **השעות שמוגדרות כשמפעילים:** גיליון ב-07:00, עדכון צהריים ב-13:00, עדכון ערב ב-19:00, סבב שמות בימי ראשון ב-10:00, וסיכום שבועי בשישי ב-12:00.

**מודל:** כל הסוכנים רצים על Sonnet 5.5 (`claude-sonnet-5-5`, ב-`company.json` תחת `defaults.model`). אפשר לקבוע מודל אחר לסוכן מסוים עם `"model"` בשורה שלו, ואז `/newsroom setup`.

## מה אתה מחליט
- **שם:** פעם בשבוע מגיעים 3 מועמדים עם בדיקות. בוחרים אחד או דוחים את כולם עם סיבה. הלוגו מתחיל רק אחרי בחירה.
- **גיליון שנפסל פעמיים:** בודק העובדות פסל פעמיים — מגיע אליך לאישור או לביטול.
- **שינויים בהנחיות:** העורך הראשי מציע, אתה מאשר.

## לשנות משהו
- **תפקיד או תקציב:** עורכים את `company.json`, ואז `/newsroom setup`.
- **הנחיות סוכן:** עורכים את הקובץ ב-`agents/`. הסוכן קורא אותו בריצה הבאה.
- **הכל נעצר:** `/newsroom stop`. אין שרת — אין ריצות ואין עלות.

## דרישות
- Paperclip רץ עם Node 24 דרך `npx -p node@24`. Node של המחשב (22) לא משתנה.
- **כלי `claude` בשורת הפקודה צריך להיות מחובר** — הסוכנים רצים דרכו. בדיקה: `claude -p "hi"` בטרמינל. אם מופיע "OAuth session expired", מריצים `claude` בטרמינל ומתחברים עם `/login`.
- השרת צריך לרוץ ב-07:00 (`/newsroom start`; הוא ממשיך לרוץ גם אחרי שסוגרים את Claude Code). אם המחשב כבוי, השגרה רצה כשהשרת עולה שוב.
- **הצומת `C:\pam`:** הסוכנים ותיקיית הנתונים של Paperclip עובדים דרך `C:\pam`, צומת (junction) לתיקייה הזו, כי Paperclip שובר ב-Windows נתיבים עם רווחים. אם הצומת נמחק, יוצרים אותו מחדש: `mklink /J C:\pam "C:\pysical ai magazine"` בחלון cmd. מחיקת הצומת לא מוחקת קבצים.
- **ה-hooks האישיים שלך כבויים לסוכנים בלבד** (`newsroom/agent-settings.json`). בלי זה כל פעולה של סוכן פותחת חלון node. בסשנים שלך הם ממשיכים לעבוד כרגיל.
- כל הסוכנים רצים בלי לשאול הרשאות (ברירת המחדל של Paperclip). `.claude/settings.json` של הפרויקט חוסם להם פעולות הרסניות: דחיפה בכוח, `reset --hard`, `rm -rf`, ופריסה ישירה ל-Vercel.

## הקמה מאפס (רק פעם אחת, כבר בוצע)
```
npx -y -p node@24 -p paperclipai@latest paperclipai onboard --yes --data-dir newsroom/.paperclip
node scripts/newsroom.mjs setup
```
ה-CLI עובד גם בלי המוד: `node scripts/newsroom.mjs status` (וכל שאר הפקודות).
